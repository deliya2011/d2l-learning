# CAICP 大纲与 d2l 的差距清单

用途：出卷与补课时对照。**d2l 是主线**，但 CAICP 大纲有一部分内容 d2l 不讲或只带一句，
这部分需要单独补，不能指望学完 d2l 自然就会。

- `gaps.md`：逐条对照结果（完全没讲 / 只提过 / 讲了但口径不同）
- 每条标了大纲编号（见 `caicp/outline-j.md`、`caicp/outline-s.md`）

判断标准：
- **没讲**：d2l 讲义与题目里找不到对应内容
- **只提过**：出现过名词但没有展开，靠 d2l 学不会
- **口径不同**：d2l 讲了相邻概念，但 CAICP 要的是另一种形式（例如 d2l 用 torch，CAICP 要 NumPy / sklearn）
