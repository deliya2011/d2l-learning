# 差距清单：CAICP 大纲 vs d2l

对照对象：`notes/a0`–`notes/b11`（已备课部分）与 `PLAN.md` 的 B 阶段路线。
逐条结论分三类：**没讲**、**只提过**、**口径不同**。

## 一、完全没讲（必须单独补）

| J1-08 | 伦理：认知外包、隐私版权、深度伪造 | 同上 |

## 三、口径不同（d2l 讲了相邻概念，但考法不同）

| 编号 | 内容 | 差异 |
|---|---|---|
| S1-02 | KNN、SVM、K-means、决策树 | d2l 只讲线性回归/softmax/MLP；这四个算法要按 CAICP 的"知道区别与用途"补 |
| S1-04 | 混淆矩阵 | B07 讲过，但 CAICP 会把它放在材料题里算指标（查准/查全/准确率），要练计算 |
| S2-08 | Pandas | B02 只用到 `read_csv`/`fillna`/`get_dummies`，CAICP 要更完整的数据处理 |
| S2-15 | 卷积、Sigmoid、ReLU 的"按规则运算" | d2l 用框架算，CAICP 可能要求手算小矩阵 |

## 四、d2l 覆盖得好的部分（不用补）

- 线性回归、softmax、MLP 的原理与实现（B06–B08）
- 反向传播与梯度下降（B04、B11）
- 过拟合、权重衰减、丢弃法（B09、B10）
- 卷积网络、Transformer 的结构（B15–B18、B24）
- Python 基础语法、列表、字符串、类与对象（A1）
- 概率基础、贝叶斯（B05）
- 线性代数、微积分（B03、B04）

## 五、建议的补课优先级

1. **先补 Python 缺口**（数制、递归、模块、字典/集合、lambda 三件套）——J 级客观题与编程题都直接考
2. **再补 AI 知识缺口**（伦理、数据形态、里程碑细节、热点、AI for Science）——背诵型，性价比高
3. **算法类**（DFS/BFS、排序、贪心）——J 级第二轮编程题会用到
4. **S 级特色**（sklearn、NumPy、Matplotlib、CNN 手算、FSM、正负反馈）——S 级第二轮的重点
5. **数学小项**（二次方程、MAE、均匀/二项分布、极限）——零散但容易补
