# B08 代码题：5 项全过，T6 三处正确

## 目标

实现 `work/b08/b08.py` 的 T1–T6，验收 `just check-remote b08`。

## 讲了什么

三处：

1. **`mlp_forward` 缺拉平**：断言传 `(4, 1, 28, 28)`，`X @ W1` 形状对不上。
   在函数开头加 `X = X.reshape(-1, W1.shape[0])`。
2. **T4 多乘了 `y.numel()`**：`cross_entropy` 返回的是**和**，`tot += l.item() * y.numel()`
   把每批损失放大 batch 倍，平均损失变成 267.9。改成 `tot += l.item()`。
3. **T5 又改反了**：`nn.CrossEntropyLoss` 默认返回**平均**，所以 T5 需要
   `tot += l.item() * y.numel()` 还原成和，再除以总样本数。学习者一度把两处都改成
   `l.item()`，T5 变成 0.0034；改回后通过。

顺带建立了**两边用 git 同步**的流程（本机 push → 远端 pull → `check-remote`），
因为出现过"本机改了、远端跑旧代码"的误判。

