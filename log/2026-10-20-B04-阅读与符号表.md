# B04 阅读开始，讲义补符号表

## 目标

学习者开始读 B04（2.4 微积分 + 2.5 自动微分），说明**没学过导数和微分**，要求讲义标注数学符号含义。

## 讲了什么

### 读前的五个概念（口述）

导数（瞬时变化率/切线斜率）、微分（线性近似）、偏导（其余变量当常数）、
梯度（偏导排成向量，指向上升最快方向）、链式法则（相乘 + 多路径相加）。
用 $f(x)=3x^2-4x$ 在 $x=1$ 处导数为 2 做例子。

### 讲义补丁：符号表

`notes/b04-autograd.md` 开头新增「符号表（没学过微积分先看这个）」，逐个解释本章出现的记号：
标量/向量/矩阵的写法、$\in$、$\mathbb{R}^n$、$\top$、$f'(x)$ 与 $\frac{dy}{dx}$、
$\frac{\partial y}{\partial x_i}$、$\nabla$、$\sum$、$\lim$、范数、$O(h^2)$、雅可比 $\mathbf{J}$、
向量-雅可比积、$\odot$、损失与参数记号、$\hat{y}$、$\approx$。末尾用三句话概括
"导数 / 偏导 / 梯度"的主干。

同时把讲义开头"对应原文"改成第二版 2.4、2.5，v1 的部分标注为历史参考。

## 学习者的产出

两题自查（关书）：

```
1.在x=1处的导数为2，即x=1时3x^2-4x的切线斜率为2
2.h太小时 f(x+h)-f(x) 是相近数相减，有效位被吃掉，舍入误差再被h除而放大
```

## 考核结果

两题都通过：导数求值正确、解释到了切线斜率；数值差分的两种误差（截断 vs 舍入）
说清了"h 太小"那一半。**阅读过关。**

实际读的是 2.4 + 2.5 两节（原计划今晚只读 2.4），用时约 56 分钟，预算 50 分钟，比值 1.12。
