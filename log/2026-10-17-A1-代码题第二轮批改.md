## 讲了什么

### T1 第三版的取舍

第二版是 `self.start += step; return self.start + self.step - 1`，`self.step` 恒为 0，
所以每次返回值都少 1。第三版把返回值改成当前值本身，并在 `__call__` 里让 `self.step` 承担
"调用次数"的计数：

```python
def __call__(self, step=1):
    self.step += 1
    self.start += step
    return self.start
```

属性名仍是 `self.start` / `self.step`（规格里叫"当前值"与"调用次数"），行为全部正确。
**名称与含义略有错位，但语义对了，不改他的代码**——这一章考的是 dunder 的行为，
不是变量命名；命名风格留到后面写长代码时再说。
