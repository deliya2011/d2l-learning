# B08 口试（必会 4/4，通过）

## 目标

关书答 `exercises/b08/oral.md` 的 9 题，判定 B08 是否结课。

## 讲了什么

两处补答：

- **Q7**：学习者答的是"简洁版用了哪些封装"（`nn.Flatten`/`nn.Linear`/`nn.ReLU`），
  没做**对位比较**。题目要的是三处差别：激活函数手写函数 vs `nn.ReLU()` 子层、
  输入维自己定 vs 写死 784、拉平手动 reshape vs `nn.Flatten()`。
- **Q8**：答"取 2 的幂，内存分配/寻址友好"。这是经验说法，不是讲义的口径——256 是书上取的
  超参数，**没有严格依据**，是"容量 vs 参数/训练成本"的折中；2 的幂只是常见习惯。

Q1 有一处笔误："不加线性层"应为"不加非线性"。

## 学习者的产出

前六题：

```
Q1 联立式 + 两个偏置合成一个新偏置 → 隐藏层白加
Q2 逐元素；混合会破坏"线性混合 / 逐点非线性"的分工
Q4 默认 ReLU；sigmoid 0.25、tanh 1，连乘梯度消失
Q6 203530，主要花在隐藏层（784×256=200704）
Q3 值域 [0,∞)、(0,1)、(-1,1)
Q5 数值一样；relu 有 inplace、专门底层实现与反向
```

收尾：

```
Q7 简洁版用了 nn.Flatten / nn.Linear(784,256) / nn.ReLU / nn.Linear(256,10)
Q8 取 2 的幂，内存分配与寻址更友好
Q9 不报错；精度与 B07 线性模型几乎一样，两个线性层等价于一层，容量没增加
```
