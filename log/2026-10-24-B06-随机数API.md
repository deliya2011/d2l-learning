# B06 讲义补随机数 API

## 目标

学习者在写 T1 时指出：`torch.normal` 的用法讲义里没写。按仓库规则（题目用到的 API 必须在
讲义里讲过），补讲义。

## 讲了什么

检查后发现讲义只有一句"`torch.normal(mean, std, size=...)` 返回指定形状的张量"，
没有讲两种签名、标准差与方差的区别、可复现的写法。新增 `### 4.1.1 随机数怎么造`：

- `torch.randn(size)`：标准正态
- `torch.normal(mean, std, size=...)`：标量形式；第二个参数是**标准差**
- `torch.normal(mean_tensor, std_tensor)`：张量形式，**不能传 `size`**
- 可复现：`torch.Generator().manual_seed(seed)` + `generator=g`
- 三个易错点：std 不是方差；`randn(size) * sigma` 的等价写法；两套签名不能混用

同时在命令速查表补了四行。
