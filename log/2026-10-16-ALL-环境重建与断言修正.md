# 环境迁移到本机：重建 venv、装 just、修 A0 断言

## 目标

之前的运行环境在另一台有显卡的机器上（Windows）。本机迁到 Linux 之后 `.venv` 与 `just`
都不存在，`A1` 无法开工。本次把环境在本机重建，并检查验收脚本是否还能用。

## 讲了什么

未授课。环境层面的四处事实变化：

1. **解释器与依赖**：系统 Python 3.14.8，仓库内 `.venv` 重建，torch/torchvision 装
   `2.14.1+cpu` / `0.29.1+cpu`（与 `requirements.txt` 一致），其余同清单。
2. **`just` 的安装方式**：pacman 装不了（本机 sudo 被 `no new privileges` 挡住），
   改用官方 release 的静态二进制，放在 `~/.local/bin/just`（1.59.0），并把该目录加进
   `~/.zshrc` / `~/.bashrc` 的 PATH。
3. **GitHub 推送链路**：本机直连 github.com 超时，走本机代理可达；`gh` 已装（`/usr/bin/gh`），
   用设备授权登录后，`gh auth setup-git` 把凭据接入 git。
4. **数据**：Fashion-MNIST 首次运行自动下载到 `data/`（82 MB，已被 `.gitignore` 覆盖）。
