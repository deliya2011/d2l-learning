# B06 讲义：每个公式加一句含义

## 目标

学习者要求"讲义的每个带符号的式子，都在后面加一句解释含义"。

## 讲了什么

### 独立公式块：11 个全部加了解释

| 公式 | 加的解释在说什么 |
|---|---|
| $\hat{y}=x_1w_1+x_2w_2+b$ | 算一条直线的预测值：特征乘权重再相加，加偏置 |
| $\hat{\mathbf{y}}=\mathbf{X}\mathbf{w}+b$ | 一次算一整批，不必逐样本循环 |
| $\ell^{(i)}=\frac{1}{2}(\hat y-y)^2$ | 量一个样本错得多离谱；$\frac12$ 为求导约掉 2 |
| $\ell=\frac1n\sum\ell^{(i)}$ | 量整个数据集错得多离谱，训练要压低的数 |
| $\operatorname{argmin}$ 式 | 训练目标：挑让平均误差最小的参数；argmin 返回参数不是最小值 |
| $\mathbf{y}=\mathbf{X}\mathbf{w}+b+\boldsymbol\epsilon$ | 数据怎么来的：线性部分加观测不到的噪声 |
| 似然乘积式 | 参数给定时观测到这组标签的概率；连乘来自样本独立 |
| 负对数似然式 | 取对数把连乘变求和，第一项与参数无关 |
| $\mathbf{w}\leftarrow\mathbf{w}-\eta\nabla\ell$ | 一步更新：沿梯度反方向挪，步长由学习率定 |
| 小批量更新式 | 只抽 $|\mathcal{B}|$ 个样本估全量梯度 |
| $p\leftarrow p-\frac{\eta}{|\mathcal{B}|}p.\text{grad}$ | 代码里的一步；除以批量大小把和变回平均 |

### 行内式子：补两处

- 向量写法 $\hat{y}=\mathbf{w}^\top\mathbf{x}+b$：说明它就是逐项内积，转置是为了"行乘列得标量"
- 造数据的真参数 $[2,-3.4]^\top$ 与 $4.2$：说明这是写死的，训练要只凭数据估回来

### 顺手修正一处笔误

原文写"$\hat{\mathbf{x}} \in \mathbb{R}^2$"，输入向量不该带帽子，改为 $\mathbf{x}$。

## 口径说明

独立公式块全部加。行内公式只给"完整式子"加；纯符号引用（如 $\mathbf{w}$、$\mathbf{X}$、$\eta$）不加，
否则每句话后面都拖一句解释，反而读不动。若要求行内全加，说一声再补。
