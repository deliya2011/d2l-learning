# 教材口径更正：纸质书也是第二版

## 目标

学习者在 B02 阅读开始时指出：他没有第一版的书，**纸质书和电子书都是第二版**。
仓库此前全部按"纸质书 = 第一版（MXNet）"组织，需要当场更正，并修掉会把他指到错误章节的地方。

## 讲了什么

### 影响面

不是一处笔误，是一个贯穿全仓库的假设：

| 位置 | 原来的假设 | 更正后 |
|---|---|---|
| `PLAN.md` 教材行、两条硬规则 | 纸质书第一版（MXNet），代码自己译成 torch | 纸质书第二版（PyTorch），无翻译任务 |
| `README.md` 开头与表格 | 第一版纸质书、MXNet、框架 torch 2.14+CUDA | 第二版、PyTorch、本机 CPU 版 |
| `AGENTS.md` 教学事实、绝对规则 1、d2l 解锁规则、讲义讲知识一节 | 纸质书是 v1、`d2lzh`、MXNet 对照 | 纸质书是 v2、`d2l` 包、规则改为"要求手写处不许调封装" |
| `notes/chapter-map.md` | v1 ↔ v2 换算表 | 加更正说明：现在两份同版，不再需要换算 |
| `notes/d2lzh-unlock-table.md` | v1 的 `d2lzh` 清单 | 标注为历史参考 |
| `exercises/b01/b02/b03/b04/b05/b06/b07/b08/READING.md` | 指向 v1 节号或"附录" | 改为 v2 节号 |
| `notes/b03…b08` 的"与书对应"表与正文 | "纸质书（第一版）"列、v1 章节号 | 列名改第二版，并加口径说明；v1 编号以在线列為准 |
| `notes/b02-data-ops.md` | 表头两列、第 1 节讲 v1/v2 差异 | 改为第二版单一口径；第 1 节改作 MXNet 历史背景 |

**最直接的一处**：我原本让学习者读"纸质书 2.2 数据操作"，在第二版里 2.2 是「数据预处理」，
数据操作是 **2.1**。已当场纠正为 2.1 + 2.2。

### 没有改的东西

`log/` 里的历史记录不动——那些是当时的事实（当时确实以为纸质书是 v1）。
`notes/b03…b08` 的表格里，v1 的章节号暂时保留在"纸质书"一列，但每张表上方加了口径说明：
**以"在线（第二版）"一列为准**，下次修订把两列合并。
