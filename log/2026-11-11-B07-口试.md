# B07 口试（必会 4/4，补答后通过）

## 目标

关书答 `exercises/b07/oral.md` 的 9 题，判定 B07 是否结课。

## 讲了什么

### Q1 的两个性质

首答把"保序"当成了两个性质之一。正确的是**非负**与**和为 1**；保序是附带性质，
它保证 `argmax` 在 logits 上与在概率上一致，所以推理时不必算 softmax。补答把三点分开说清了。

### Q2 的例子

学习者坚持他举了正确的例子。复核后确认他的意思是对的：**平方损失衡量的是概率数值的接近程度，
不是分类是否正确**——分类对但置信度低的那组，平方损失可以比分类错但置信度高的那组更大。
我第一遍把"甲的 loss 大、分类对"读成了矛盾，是读漏。缺的只是具体数值，建议下次直接用数字。

### Q3 的"打包必要"

补答：不打包时先 softmax 再取 log，$\hat y$ 接近 0 时 `log` 变成 $-\infty$；
框架的 `log_softmax` 把两步合并计算，数值精度更好。

## 学习者的产出

`work/b07/b07口试.md`，原话摘录：

```
1. softmax 是 (0,1) 内且总和为 1，保序保证 argmax 一致，推理不必算 softmax
2. 平方损失看重数值大小而不是分类正确，所以与任务目标相反
3. ∂l/∂o_j = ŷ_j - y_j；不打包时 log(ŷ) 在 ŷ→0 时变成 -∞；log_softmax 合并计算精度更好
4. 接收 logits；传 softmax 输出会做两次 softmax，收敛变慢、梯度变小
5-9. 只剩一项 / 等价似然 / 上溢减 max / 类别不平衡 / dim=0 每列归一化
```
