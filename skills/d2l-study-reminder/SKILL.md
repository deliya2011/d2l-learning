# d2l 学习节奏与防溜号

## 什么时候用

- 学习者开始一个带时间预期的任务，例如"开始做 A0 任务一"
- 一次提醒之后他没回话，需要升级提醒强度
- 判断他是不是溜号了

## 机制

三步循环，用后台 job 当定时器。

### 1. 起心跳

给他任务的同时起一个后台 job：

```bash
sleep 1800; echo "心跳：该问 <单元> <任务> 的进度了"
```

`run_in_background` 设为 true。**job 跑完会通知 AI，这就是定时器**，
不需要 cron、systemd timer 或任何外部调度。

起 job 之前先记下当前时刻，它同时充当本次任务的计时起点；他报告完成时再记一次，
差值写进日志的"用时对比"节。

时长按时间预算来（见下表）。

**写代码那一段不要中途打断。** 编程中断后只有 10% 的会话能在 1 分钟内恢复编码
（Parnin & Rugaber 2011），中断越长恢复越慢（Monk 等 2008）。所以分两类处理：

- 读讲义、读书、口试：按预算起心跳，到点就问
- **写代码：心跳时长按整段的长度设（至少 60 分钟），到点时问的是"这一段落停了吗"**，
  不要中途插进去问做到哪了

**段末提醒他休息。** 说法具体一点：离开屏幕、走动 5 到 15 分钟、闭眼静坐都行。
**不要说"看会儿手机"**——对照研究里手机休息约等于不休息（Kang & Kurtzberg 2019），
而且会留下注意力残留。完整的休息规则见仓库里的 `notes/learning-rhythm.md`。

### 2. 到点问进度

心跳到达时如果他还没主动报告，就发消息问他做到哪了。问具体一点，
例如"任务一跑通了吗，输出的形状那几行对上了没"，不要只问"做完了吗"。

可以先看一眼 `work/` 下有没有文件、文件多大，这样问得具体些。
**但只看不批**：他可能正在调试，中间状态不是交付物。批改等他明确说"做完了"再开始。

同时起一个五分钟的后台 job：

```bash
sleep 300; echo "心跳：五分钟没回话，该响铃了"
```

### 3. 没回话就响铃

五分钟的 job 到点时他还没回话，用扬声器叫他：

```bash
tools/remind.sh 3 "回来学习"
```

- 第一个参数是响几声，溜号时用 3
- 第二个参数用 piper 念一遍中文，留空就只响铃。没装 piper 或没有模型时自动跳过朗读
- 提示音走 paplay，音量在脚本里写死成约 69%（`D2L_VOL_SOUND` 可覆盖），
  不跟系统音量挂钩；系统音量太低时仍然听不见，必要时让他调高

他回话之后，如果任务还没结束，从第 1 步重新起心跳。

## 时间预算

| 任务类型 | 预算 | 心跳怎么设 |
|---|---|---|
| 读一节讲义 | 20-30 分钟 | 按预算 |
| 读纸质书一节 | 30-40 分钟 | 按预算 |
| 口试 | 20 分钟 | 按预算 |
| 写代码 | 至少 60 分钟一段 | 按整段长度，只在段末问 |

## 脚本

`tools/remind.sh` 提示音走 `paplay`，取不到声音服务时退回终端响铃（`\a`）。
两者都失败只是静默跳过，不会报错退出。

```bash
tools/remind.sh                        # 一声提示音
tools/remind.sh 3                      # 三声
tools/remind.sh 2 "该看进度了"           # 两声，再念一遍
```

**语音需要 piper**，没装时自动跳过朗读，只响提示音：

```bash
pacman -S piper
# 模型放 ~/.local/share/piper/zh_CN-huayan-medium.onnx（连同 .onnx.json）
```

脚本开头会补 `XDG_RUNTIME_DIR` 与 `DBUS_SESSION_BUS_ADDRESS`。从没有桌面会话的环境
（沙盒、后台 job）里调用时缺这两个变量，`paplay` 会报
`pa_context_connect() failed: Connection refused`，而脚本里的 `|| true` 会把它吞掉，
看起来像播过了。

音量写死在脚本里（`D2L_VOL_SOUND` 约 69%、`D2L_VOL_VOICE` 约 92%），
可用环境变量覆盖。

## 注意

- 提醒别太频繁。一个任务一个心跳就够，不要在半小时里问三次。
- 扬声器是兜底。他人在电脑前时，在对话里喊一声就够，不必响铃。
- 需要知道他今天的作息时直接问，不要按常规作息想当然，也别提"早上"。
