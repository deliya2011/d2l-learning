A1:判据：返回值被使用或产生了可观察的副作用。
例一：返回新对象：
```python
s = "hello"
s.upper() #返回新字符串"HELLO"被丢弃，s仍是"hello"
```
有副作用：
```python
lst = [1, 2, 3]
lst.sort() #原地排序，修改lst，返回None
```
A2:`torch.arange(0, 1, 0.25)`有4个元素,分别为0,0.25,0.5,0.75
`torch.linspace(0, 1, 5)`有5个元素，分别为0,0.25,0.5,0.75,1
