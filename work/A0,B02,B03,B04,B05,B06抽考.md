1. `torch.arange(0, 1, 0.25)` 与 `torch.linspace(0, 1, 5)` 各几个元素、内容是什么？
`torch.arange(0,1,0.25)`有4个元素，分别是0,0.25,0.5,0.75,`torch.linspace(0,1,5)`有五个元素，分别是0,0.25,0.5,0.75,1
2.  `reshape` 与 `view` 的区别是什么？张量**不连续**时，两者各会怎样？
reshape和view对非连续张量的处理方式不同，view要求张量内存必须连续，否则报错，reshape不连续时会自动复制数据来完成任务
3.  `A` 形状 `(5, 4)`：`torch.cat([A, A], dim=0)`、`torch.cat([A, A], dim=1)`、`torch.stack([A, A], dim=0)` 各得到什么形状？
   (10,4) (5,8) (2,5,4)
4. `with torch.no_grad():` 与 `.detach()` 各举一个使用场景。
	计算梯度时`with torch.no_grad()`，`.detach()`对某个张量单独detach
5. 独立与互斥的区别是什么？各自的联合概率怎么算？
独立是，一个时间发生不影响另一个事件发生，互斥是两个事件不能同时发生，各自的联合概率，互斥事件$P(A \cap B) = 0$,独立事件$P(A \cap B) = P(A)\,P(B)$
6. SGD 更新式里为什么要**除以批量大小**？不除会怎样？
为了让梯度的量级和单样本时保持一致，让学习率在不同batch size下具有可比性，如果不除，梯度会随batch size线性放大，等于把学习率放大了batch倍
