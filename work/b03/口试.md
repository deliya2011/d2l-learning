Q1:* 是逐元素乘法，@则是求矩阵-向量积，*要求维度大小相等或其中的维度的大小为1，@要求内维相等，即A的末维=B的倒数第二维
Q2:指定哪个 `dim`，输出里那个轴就消失。`dim` 可以传一个列表一次压掉多个轴。keepdim=True保留了维度，使轴仍然存在
Q3:点积：torch.dot()，矩阵-向量积：torch.mv()，矩阵-矩阵乘法：torch.mm()，@对应矩阵-向量积

Q4:第一个形状是(10,4),沿第0维拼接，第二个形状是(5,8)，沿第1维拼接，第三个形状是(2,5,4)，是沿新维度堆叠
Q5:三维时的.T会翻转所有轴，同时报错，三维时容易让人误以为符合直觉，实际规则是全维度反转，本质上不符合二维转置的直觉。
Q6:范数把向量映射成标量，用来衡量“有多大”。$L_2$ 范数是元素平方和的平方根，$L_1$ 范数是元素绝对值之和。

Q7:最后两维做矩阵乘法，前面的所有维度视为“批量维”，按广播规则对齐。
Q8:所有值变为NaN，应加上norms = torch.where(norms == 0, torch.ones_like(norms), norms)将所有0补充为1
Q9:不传会对所有维度求和，得到一个 0 维标量张量，坑：维度丢失导致后续广播/形状错误
