# NOAI 考试形式与出题规范

依据：【学术大纲】NOAI 2027 的 2.2、2.3 节，与 2026 NOAIP 省选真题的结构。

## 第一轮（NOAIP 省选，纸笔）

2027 大纲列出的题型：

| 题型 | 考什么 |
|---|---|
| 单选题 | A、B 区基础概念 |
| 多选题 | 知识广度，多个选项可能同时正确 |
| 材料分析题 | 以 AI4S 与前沿 AI 真实素材为背景，含单选与多选 |
| 程序补全题 | 给不完整的 ML/DL 代码，补全关键步骤 |

**2026 真题的参考结构**（2027 大纲已取消"概念解释"与"大段编程"）：

- 单选 15×2 = 30
- 概念解释 4×5 = 20（2027 已取消）
- 程序补全 2×10 = 20
- 编程解决问题 2×15 = 30（2027 已取消）

模拟卷按 2027 大纲设计，分值为模拟分配（以当届通知为准）：单选 15×2 + 多选 10×2 +
材料分析 2 组（每组含单选与多选，共 20 分）+ 程序补全 3×10，合计 100。

## 第二轮（NOAI 中国站，上机）

原则上 **4 道人工智能实践任务**，涉及数据处理、模型训练、模型推理、结果分析与优化。
C 区（NumPy/Pandas/Matplotlib/特征工程）与 D 区（PyTorch/CNN/RNN/GAN/NLP/CV/语音/LLM）
是这一轮的范围。

## 出题时机

**等 d2l 学习进度差不多时再开始出 NOAI 题。** 具体触发点：

- d2l 完成 B08（多层感知机）→ 可以开始出 **第一轮** 模拟（A、B 区为主）
- d2l 完成 B18（BN/ResNet）与 B24（Transformer）→ 可以出 **第二轮** 的 C、D 区任务

在那之前，只维护大纲、形式与差距清单，不出卷。

## 与 CAICP 的关系

两套考纲重叠很多（Python、ML 基础、伦理、评估指标、CNN、Transformer），但侧重点不同：

| | CAICP | NOAI |
|---|---|---|
| 第一轮 | 单选/多选/判断 | 单选/多选/材料分析/程序补全 |
| 第二轮 | 单选/多选/判断/编程（2 题） | 上机 4 道实践任务 |
| 特色 | 计算思维、应用与伦理面广 | 更偏机器学习与深度学习，含 AI4S |

出题时共用题库思路，但卷面结构分开。
