# CAICP & NOAI 模拟测试

目标是准备两套认证：

- **CAICP**（入门级 J / 进阶级 S）：从 2026-11-14 起每日一组，按下面的日程执行
- **NOAI**（NOAIP 省选 / NOAI 中国站）：大纲已整合，**等 d2l 学习进度差不多时再出题**

测试完全仿照官方真题的形式，题目原创，不抄真题原文。

## 日程与目标（2026-11-13 定）

| 阶段 | 第一轮卷 | 第二轮卷 |
|---|---|---|
| 11-14 ~ 11-22 | CAICP **J + S 融合** | CAICP **J + S 融合** |
| 11-23 ~ 11-28 | **暂停**，不出卷 | **暂停** |
| 11-29 起 | **NOAI 第一轮**（替换 CAICP 第一轮） | CAICP J + S 融合；NOAI 第二轮出题时机到后，NOAI 内容再融合进来 |

每天一组 = 第一轮 + 第二轮，两卷都出。J 组与 S 组不再分成两套卷，而是**融合在同一份卷子里**
（第一轮覆盖 J1+S1，第二轮覆盖 J2+S2）。

**目标线（一等奖水平）**：第一轮 ≥ 85 / 100，第二轮 ≥ 110 / 150。

学习者之后可能不定时在线，需要做时会告知；没有告知就不排当天的卷。

## 每日一组是什么

| 卷 | 题型 | 分值 | 建议用时 |
|---|---|---|---|
| 第一轮 | 单选 10×5 + 多选 6×5 + 判断 10×2 | 100 | 45 分钟 |
| 第二轮 | 单选 10×5 + 多选 6×5 + 判断 10×2 + 编程 2×25 | 150 | 75 分钟 |

**第二轮涵盖第一轮内容**（官方就是这样设计的），所以第二轮的客观题会带第一轮的基础点。
难度按 **S 级**出（S 涵盖 J），J 级的考点在覆盖表里逐条登记。

## 评分

- 单选 5 分；多选 5 分（全对满分，少选得 3 分，错选 0 分）；判断 2 分
- 编程每题 25 分：正确性 20（5 组用例，每组 4 分）+ 代码风格 5
- 每天两卷合计 250 分。做完自己对答案，错题写进当天的错题清单

## NOAI 部分

- 大纲：`outline-noai.md`（A、B 区 = 第一轮省选；C、D 区 = 第二轮中国站）
- 形式：`format-noai.md`（2027 第一轮：单选/多选/材料分析/程序补全；第二轮：上机 4 道实践任务）
- **出题时机**：d2l 完成 B08 后开始出 NOAI 第一轮模拟；完成 B18 与 B24 后出第二轮任务。
  在那之前只维护大纲与差距清单，不出卷。

## 与 d2l 学习的关系

CAICP 模拟是**第二条线**，不替代 d2l 的主线。每天至少一课 d2l 新内容的要求不变；
CAICP 的卷子放在 d2l 之后做，或按当天精力分配。
