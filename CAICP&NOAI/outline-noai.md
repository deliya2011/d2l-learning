# NOAI 2027 大纲条目

来源：【学术大纲】NOAI 2027（2026 年 10 月修订）。A、B 区对应第一轮（NOAIP 省选，纸笔）；
C、D 区对应第二轮（NOAI 中国站，上机）。

## A 区：一般性计算机技能（第一轮）

| 编号 | 条目 |
|---|---|
| NA-01 | 基本语法：算术、关系、输入输出 |
| NA-02 | 程序结构：顺序、分支、循环 |
| NA-03 | 数据结构：字符串、列表、字典、元组及基本操作 |
| NA-04 | 函数、模块、包的概念；内置函数与 `os`/`math`/`random`/`sys`；自定义函数 |
| NA-05 | 在文档帮助下使用第三方库解决简单问题 |
| NA-06 | 读懂代码；在文档帮助下实现排序、查找等简单算法 |
