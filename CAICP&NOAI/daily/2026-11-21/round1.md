**9.** 运行下列程序，输出是（ ）

```python
class Gate:
    def __init__(self, limit):
        self.limit = limit
        self.used = 0

    def admit(self, n):
        if self.used + n <= self.limit:
            self.used += n
            return True
        return False

g = Gate(5)
a = g.admit(3)
b = g.admit(4)
c = g.admit(2)
print(a, b, c, g.used)
```

A. `True True False 3`
B. `True False True 5`
C. `True False False 3`
D. `True True True 9`
