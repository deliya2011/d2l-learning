## 四、编程题（2 题，每题 25 分，共 50 分）

### 27. 成绩等级统计（25 分）

**题目**：给定 $n$ 个学生的分数（0–100 的整数），统计四个等级的人数并输出：

- A：90–100
- B：80–89
- C：70–79
- D：0–69

**输入格式**：

- 第 1 行：整数 $n$（$1 \le n \le 1000$）
- 第 2 行：$n$ 个整数，空格分隔

**输出格式**：

- 一行：`A B C D` 四个整数，用空格分隔

**样例输入**：

```
5
95 82 70 69 100
```

**样例输出**：

```
2 1 1 1
```

### 28. 库存连续预警（25 分）

**题目**：给定 $n$ 天的库存量和一个阈值 $t$。找出**第一次**出现"连续 3 天库存都严格小于 $t$"的
起始天（从 1 开始计数）。如果不存在，输出 `-1`。

**输入格式**：

- 第 1 行：整数 $n$ 与阈值 $t$，空格分隔（$1 \le n \le 1000$，$0 \le t \le 10^6$）
- 第 2 行：$n$ 个整数，空格分隔

**输出格式**：

- 一行：起始天的编号，或 `-1`

**样例输入**：

```
7 10
12 8 9 7 6 11 3
```

**样例输出**：

```
2
```

（第 2、3、4 天为 8、9、7，都小于 10。）

**评分要点**：正确性 20（5 组用例各 4：样例、恰好 3 天、中间被打断、不存在、n<3），风格 5。
