## 编程题

### 27. 图书借阅统计

```python
n = int(input())
tot = {}
order = []
for _ in range(n):
    name, cnt = input().split()
    cnt = int(cnt)
    if name not in tot:
        tot[name] = 0
        order.append(name)
    tot[name] += cnt

for i, name in enumerate(sorted(order, key=lambda s: -tot[s]), 1):
    print(i, name, tot[name])
```

要点：`sorted` 稳定，按次数降序即保持同分书名的首次出现顺序。

### 28. 温度记录填补

```python
n = int(input())
a = list(map(int, input().split()))
missing = sum(1 for x in a if x == -1)

last = None
left = [None] * n
for i, x in enumerate(a):
    if x != -1:
        last = x
    left[i] = last

right_first = next(x for x in a if x != -1)
filled = [right_first if left[i] is None else left[i] for i in range(n)]

print(max(filled), min(filled), f"{sum(filled)/n:.2f}", missing)
```

要点：左侧最近有效值一次扫描；开头缺失用右侧第一个有效值；平均值用 `f"{x:.2f}"` 固定两位
（`round` 不补零，这是 11-14 第二轮的重考考点）。
