## 编程题

### 27. 成绩等级统计

```python
n = int(input())
scores = list(map(int, input().split()))
cnt = [0, 0, 0, 0]   # A, B, C, D
for s in scores:
    if s >= 90:
        cnt[0] += 1
    elif s >= 80:
        cnt[1] += 1
    elif s >= 70:
        cnt[2] += 1
    else:
        cnt[3] += 1
print(*cnt)
```

要点：从高到低判断区间，边界 90/80/70 归入上一档。

### 28. 库存连续预警

```python
n, t = map(int, input().split())
a = list(map(int, input().split()))
ans = -1
for i in range(n - 2):
    if a[i] < t and a[i+1] < t and a[i+2] < t:
        ans = i + 1
        break
print(ans)
```

要点：滑动窗口长度为 3，`range(n-2)` 防止越界；找到第一个就 `break`。
