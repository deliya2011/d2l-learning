## 编程题

### 27. 课程总评与排名

```python
n = int(input())
order = []
score = {}
for _ in range(n):
    name, a, b = input().split()
    order.append(name)
    score[name] = int(a) * 0.3 + int(b) * 0.7

rank = sorted(order, key=lambda s: -score[s])
for i, name in enumerate(rank[:3], 1):
    print(i, name, f"{score[name]:.1f}")
```

### 28. 日志级别分析

```python
n = int(input())
cnt = {}
first = {}
order = []
for _ in range(n):
    t, level, msg = input().split(maxsplit=2)
    if level not in cnt:
        cnt[level] = 0
        first[level] = msg
        order.append(level)
    cnt[level] += 1

best = max(order, key=lambda lv: (cnt[lv], -order.index(lv)))
print(best)
print(first[best])
```
