### 27. 课程总评与排名（25 分）

**题目**：给定 $n$ 个学生的平时成绩与期末成绩，总分 = 平时 × 0.3 + 期末 × 0.7。
按总分从高到低输出**前 3 名**（不足 3 人输出全部），每行"排名 姓名 总分"，总分保留**一位小数**。
总分相同时，按姓名首次出现的先后排列。

**输入格式**：

- 第 1 行：整数 $n$（$1 \le n \le 1000$）
- 接下来 $n$ 行：每行"姓名 平时 期末"，两个成绩都是 0–100 的整数

**输出格式**：

- 最多 3 行，每行"排名 姓名 总分"

**样例输入**：

```
4
Li 80 90
Wang 70 95
Zhao 90 80
Chen 60 70
```

**样例输出**：

```
1 Wang 87.5
2 Li 87.0
3 Zhao 83.0
```

### 28. 日志级别分析（25 分）

**题目**：给定 $n$ 行日志，每行"时间 级别 消息"，级别只有 `ERROR`、`WARN`、`INFO` 三种。
统计各出现次数，输出**数量最多**的级别，再输出该级别**第一条**日志的消息。
数量并列时，取**先出现**的级别。

**输入格式**：

- 第 1 行：整数 $n$（$1 \le n \le 1000$）
- 接下来 $n$ 行：时间（不含空格）、级别、消息（消息可含空格）

**输出格式**：

- 第一行：出现最多的级别
- 第二行：该级别的第一条消息

**样例输入**：

```
5
10:01 ERROR disk full
10:02 INFO start
10:03 ERROR timeout
10:04 WARN low memory
10:05 INFO done
```

**样例输出**：

```
ERROR
disk full
```

**评分要点**：正确性 20（5 组用例各 4：样例、并列取先出现、单条、全同级、消息含空格），风格 5。
