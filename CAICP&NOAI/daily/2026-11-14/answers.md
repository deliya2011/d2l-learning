### 27. 气象站降雨统计

```python
n = int(input())
totals = {}          # 站点 -> 总降雨
order = []           # 首次出现顺序
for _ in range(n):
    line = input().split()
    name, rain = line[0], int(line[1])
    if name not in totals:
        totals[name] = 0
        order.append(name)
    totals[name] += rain

# 排序稳定：总降雨降序，相同则保持首次出现顺序
rank = sorted(order, key=lambda s: -totals[s])
for i, name in enumerate(rank, 1):
    print(i, name, totals[name])
```

要点：`sorted` 是稳定排序，按总降雨降序排即可保持同分站点的首次出现顺序。

### 28. 传感器读数清洗

```python
n = int(input())
a = list(map(int, input().split()))
missing = sum(1 for x in a if x == -1)

# 左侧最近有效值
last = None
left = [None] * n
for i, x in enumerate(a):
    if x != -1:
        last = x
    left[i] = last

# 开头连续缺失：用右侧第一个有效值
right_first = next(x for x in a if x != -1)
filled = [right_first if left[i] is None else left[i] for i in range(n)]

print(min(filled), max(filled), round(sum(filled) / n, 2), missing)
```

要点：先统计缺失个数（在填补前）；两次扫描处理"左侧有效值"与"开头缺失"；`round` 保留两位。

评分：5 组用例每组 4 分（组内全过才得分）；代码风格 5 分（命名、注释、无冗余）。
