### 27. 气象站降雨统计（25 分）

**题目**：某气象站记录了 $n$ 天的降雨量（单位 mm，非负整数）。请按总降雨量从高到低排序，
输出排名、站点名与总降雨量；总降雨量相同的站点，按站点名首次出现的先后顺序排列。

**输入格式**：
- 第 1 行：整数 $n$（$1 \le n \le 1000$）
- 接下来 $n$ 行：每行"站点名 降雨量"，用一个空格分隔。站点名只含字母，长度不超过 20；
  同一站点可能出现多次。

**输出格式**：
- 共 $k$ 行（$k$ 为不同站点数），每行"排名 站点名 总降雨量"，排名从 1 开始。

**样例输入**：
```
5
A 10
B 30
A 5
C 30
B 1
```

**样例输出**：
```
1 B 31
2 C 30
3 A 15
```

**评分要点**：
1. 正确读入与按站点累加（4 分）
2. 排序规则：总降雨降序；相同则按首次出现顺序（4 分）
3. 输出格式正确（4 分）
4. 处理重复站点与边界（4 分）
5. 代码风格与注释（4 分，另 5 分为风格分）

### 28. 传感器读数清洗（25 分）

**题目**：给定一串传感器读数（整数），其中 `-1` 表示缺失。请按从左到右的顺序，
用**左侧最近的有效值**填补每个缺失值；如果开头连续多个缺失（左侧没有有效值），
用**右侧第一个有效值**填补。填补后输出：最小值、最大值、平均值（保留两位小数）、
以及缺失值的个数。

**输入格式**：
- 第 1 行：整数 $n$（$1 \le n \le 1000$）
- 第 2 行：$n$ 个整数，空格分隔，取值 $-1$ 或 $[0, 100]$
- 保证至少有一个有效值

**输出格式**：
- 一行：`最小值 最大值 平均值 缺失个数`，平均值保留两位小数。

**样例输入**：
```
6
-1 -1 20 30 -1 40
```

**样例输出**：
```
20 40 26.67 3
```

**评分要点**：
1. 正确识别缺失并统计个数（4 分）
2. 左侧最近有效值填补（4 分）
3. 开头连续缺失用右侧第一个有效值（4 分）
4. 最小 / 最大 / 平均值计算与格式（4 分）
5. 代码风格与注释（4 分，另 5 分为风格分）
