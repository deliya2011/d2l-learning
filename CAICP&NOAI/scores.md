# 模拟赛成绩与难度档

## 难度档

| 档 | 特征 |
|---|---|
| 1 | 单知识点、材料短（一两句话）；干扰项直接 |
| 2 | 材料稍长（小表格/日志），需要两步推理 |
| 3 | 单题跨两个知识点；干扰项基于常见误解 |
| 4 | 接近 S 级样卷：长材料、表格、证据强度判断、需要计算 |
| 5 | 超过样卷：新情境、多步计算、编程题带边界用例 |

**加难的方式**（按顺序用）：

1. 材料变长：从一句话变成表格 + 日志 + 注释
2. 干扰项变近：把"常见误解"做成选项
3. 跨知识点：一道题要同时用到两个概念
4. 计算变多：需要两步以上计算才能排除
5. 编程题：边界用例（空输入、除零、极值）+ 输出格式严格

## 调档规则

| 情况 | 动作 |
|---|---|
| 连续两次 ≥ 目标线 + 5 分 | 升一档 |
| 一次 ≥ 目标线 + 5 分 | 保持，下次再观察 |
| 在目标线 ±5 分内 | 保持 |
| 低于目标线 | 保持或降一档；先查材料有没有讲清楚 |
| 低于目标线 - 15 分 | 降一档 + 先补课再出卷 |

目标线：第一轮 85/100，第二轮 110/150。
