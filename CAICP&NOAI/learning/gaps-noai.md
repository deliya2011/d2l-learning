# NOAI 与 d2l 的差距清单

对照 NOAI 2027 大纲（A/B/C/D 区）与 d2l 已备课部分。结论分三类：**没讲**、**只提过**、**口径不同**。

## A 区（第一轮，Python）

| 编号 | 内容 | 结论 |
|---|---|---|
| NA-01、NA-02 | 基本语法、程序结构 | d2l 覆盖（A1） |
| NA-03 | 字符串、列表、字典、元组 | 部分覆盖：A1 有字符串/列表，字典/元组要补 |
| NA-04 | 函数、模块、包、os/math/random/sys | **没讲**（A1 不讲模块与标准库） |
| NA-05 | 文档帮助下用第三方库 | **没讲** |
| NA-06 | 读代码、排序、查找 | 部分：读代码有（A1 异常），排序/查找**没讲** |

| NB-04、NB-05 | 三学派、图灵测试、伦理 | 部分：三学派在 B01，伦理**没讲** |

| NB-07 | K-Means、DBSCAN、层次、谱聚类 | **没讲** |
| NB-08 | PCA、t-SNE、UMAP | **没讲** |
| NB-09 | 强化学习 | **只提过**（B01） |
| NB-10 | 线性/非线性 | d2l 覆盖（B08） |
| NB-11 | 概率、正态、统计、距离 | 部分：B05 覆盖概率与正态，距离要补 |

## C 区（第二轮，数据处理）

| 编号 | 内容 | 结论 |
|---|---|---|
| NC-01 | 数据清洗、可视化、统计 | 部分：B02 有清洗，可视化零散 |
| NC-02 | NumPy | **口径不同**：d2l 用 torch，NumPy 只在 B02 做互转 |
| NC-03 | Pandas | 部分：B02 有读取/缺失值/独热，查询/融合没讲 |
| NC-04 | Matplotlib | 部分：d2l 画图零散，不系统 |
| NC-05 | 特征工程（滑窗、池化、one-hot、统计特征、嵌入） | **没讲**（滑窗/嵌入） |
| NC-06 | 前向填充、图像增强、分词与词汇表、分块 | **没讲** |

## 补课优先级（相对 NOAI）

1. **A 区**：模块/标准库、排序/查找——第一轮程序补全题的地基
2. **B 区**：聚类、降维、集成学习、评估指标（ROC/F1）、逻辑回归——第一轮客观题的高频点
3. **B 区背诵型**：AI4S、伦理、前沿趋势——性价比高
4. **C 区**：NumPy、Pandas、Matplotlib、特征工程——第二轮上机的地基
5. **D 区**：CNN 检测/分割、GAN、语音、LLM 部署——第二轮任务的扩展面
