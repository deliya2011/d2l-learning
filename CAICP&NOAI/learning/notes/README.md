## 怎么用

- 按编号顺序学，**不要跳**：前面的模块是后面的前置（尤其是 03 → 05 → 07）
- 每份讲义末尾有自测题，答案在折叠块里，先自己做再展开
- 模块 01 与 02 是背诵型，可以碎片时间过；03、05、07、08、09 要动笔
- 学完一份，回到 `CAICP&NOAI/learning/gaps.md` 把对应条目划掉

## 与 d2l 的关系

这些讲义只补 d2l 的**缺口**，不重复 d2l 已讲的内容（线代、微积分、概率、线性回归、
softmax、MLP、CNN、Transformer 等）。遇到交叉点会注明"回到 d2l 的哪一单元"。
