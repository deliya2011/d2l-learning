# 模块 10：NOAI 第一轮题型与材料分析

> 难度 ★★　覆盖：NA-01–06、NB-01–03　建议 30 分钟

这一份不是新知识，是**怎么考**。NOAI 第一轮题型与 CAICP 不同，练法也不同。

## 1. 题型

| 题型 | 考法 | 策略 |
|---|---|---|
| 单选 | 基础概念 | 直接选，控制速度 |
| 多选 | 知识广度，多个正确 | 逐项判断，不确定的项找反例 |
| 材料分析 | 给一段 AI4S/前沿素材，配单选或多选 | 先看问题，再回材料定位 |
| 程序补全 | 给不完整的 ML/DL 代码，填空 | 看签名、注释、上下文变量 |

## 2. 材料分析题的读法

1. **先读问题**：问的是"哪项成立"还是"哪项最稳妥"——后者要排除过度推断
2. **圈出材料里的变量与结论**：谁测了什么、得到什么数、结论是什么
3. **警惕证据强度**：
   - 一次观测不能证明"所有场景都适用"
   - 训练集上的好成绩不能证明泛化
   - 相关不等于因果
4. **排除法**：绝对化表述（"一定""必然""完全"）通常是错的

## 3. 程序补全题的常见考点

- 混淆矩阵、准确率/精确率/召回率/F1 的计算
- 数据划分（训练/验证/测试）与交叉验证
- 训练循环的顺序：清零梯度 → 前向 → 损失 → 反传 → 更新
- softmax 与交叉熵（数值稳定：减最大值）
- 标准化 / one-hot / 缺失值处理
- 设备迁移（`to(device)`）

做题步骤：先看函数名与 docstring 确认要做什么 → 找上下文里已有的变量 →
写出 1–3 行 → 用注释里的要求自查。

## 4. 常见陷阱

| 陷阱 | 正确做法 |
|---|---|
| 用准确率评价不平衡数据 | 看召回率/F1/AUC |
| 用测试集调参 | 只用验证集调，测试集最后用一次 |
| 特征里混入标签信息（泄漏） | 检查每个特征在预测时是否可得 |
| 训练误差低就宣布模型好 | 看验证误差与过拟合 |
| 把"局部最优"当"全局最优" | 凸问题才等价 |

## 5. 自测

**材料**：某团队在 2025 年用 500 条河流水位记录训练了一个预警模型，训练集准确率 98%，
在同年 50 条新记录上准确率 71%。团队据此认为模型可以直接用于全国所有河流。

1. 下列判断最稳妥的是（ ）
A. 模型训练充分，可以直接全国部署
B. 训练与测试差距大，可能过拟合或分布不同，应先扩大代表性数据再评估
C. 71% 说明模型完全无效
D. 只要再训练更久，准确率一定升到 98%

2. 要判断"分布不同"是否成立，最需要补充的材料是（ ）
A. 训练集的损失曲线
B. 新记录与训练集在河流类型、季节、传感器上的分布对比
C. 模型的参数量
D. 训练用了多少 GPU
