# 模块 04：数据形态与预处理

> 难度 ★★　覆盖：J1-03/17/18、J2-19、S2-04、NB-26、NC-05/06　建议 40 分钟

## 1. 数据的三种分类

| 分类 | 含义 | 例子 |
|---|---|---|
| 数字 / 模拟 | 离散取值 / 连续信号 | 人数 / 电压波形 |
| 结构化 / 非结构化 | 有固定行列结构 / 没有 | 成绩表 / 图像、文本、音频 |
| 单模态 / 多模态 | 一种数据类型 / 多种同时出现 | 纯文本 / 视频 + 字幕 + 音频 |

**多模态**的关键：不同模态的数据要能对齐（例如视频帧与字幕时间戳）。

## 2. 编码与解码

按给定规则把信息变成另一种表示，或反过来。例：

- 字母后移一位：`cat` → `dbu`（编码），`dbu` → `cat`（解码）
- 数字转二进制字符串：`10` → `1010`
- 摩尔斯电码、Base64、URL 编码

做这类题先写出**映射表**，再逐字符处理；注意边界（`z` 后移一位回到 `a`）。

## 3. 特征抽象与规律识别

**特征**：能区分对象的属性。例：描述"教室"可用座位数、面积、是否有投影仪；
门牌号的颜色不是有效特征。

**规律识别**：在数字串、文字序列里找重复与循环，例如 `1,2,3,1,2,3,...` 的周期是 3。

## 4. 数据清洗

一般过程：

1. **缺失值**：删行、均值/中位数填补、前向填充
2. **异常值**：3σ、箱线图、业务规则（如温度 -999）
3. **重复值**：去重
4. **不一致**：单位统一（℃ / ℉）、格式统一
5. **类型**：字符串转数值、日期解析

清洗的原则：**先理解数据再动手**；删除会丢信息，填补会引入偏差，要记录处理步骤。

## 5. 数值变换

| 方法 | 做法 | 用途 |
|---|---|---|
| 标准化（Standardization） | $z=(x-\mu)/\sigma$ | 不同量纲的特征可比 |
| 归一化（Normalization） | $x'=(x-\min)/(\max-\min)$ | 压到 [0,1] |
| One-hot | 类别展开成 0/1 向量 | 类别特征不能比大小 |
| 词嵌入 | 词映射成稠密向量 | 让语义相近的词距离近 |

## 6. 特征工程

- **滑动窗口**：按固定长度在序列上滑动，取统计量（均值、方差、最大）
- **池化**：把一块区域压成一个值（最大池化、平均池化）
- **统计特征**：均值、方差、标准差、高阶矩
- **嵌入**：用神经网络把离散对象变成向量

## 7. 数据增强

| 数据类型 | 手段 |
|---|---|
| 图像 | 翻转、裁剪、旋转、加噪、调色 |
| 语音 | 加噪、变调、变速 |
| 文本 | 掩码、同义词替换、回译 |

目的：让模型见到"同一语义的不同形态"，减轻过拟合。注意增强不能改变标签。

## 8. 数据处理细节

- **前向填充**：用左侧最近的有效值填补缺失
- **Tokenization（词元化）**：把文本切成词元
- **词汇表**：把词元映射成整数 id
- **Patching**：把图像切成小块（Transformer 视觉模型的输入）

## 9. 自测

1. "一段视频 + 它的字幕"属于哪一类数据？
2. 为什么类别特征不能直接当数字用？该怎么处理？
3. 标准化与归一化的区别是什么？
4. 图像翻转属于哪一类处理？有什么风险？
5. 前向填充遇到"开头连续缺失"怎么办？

> [!note]- 答案
> 1. 多模态（非结构化）。
> 2. 类别编号的大小没有意义；用 One-hot 编码。
> 3. 标准化减均值除标准差、结果无界；归一化压到 [0,1]。
> 4. 数据增强；如果翻转会改变标签（如区分左右手的图），就不能用。
> 5. 用右侧第一个有效值填补（或按业务规则处理）。
