# 模块 01：AI 知识与伦理

> 难度 ★　覆盖：J1-06/07/08、S1-05/06/07/08、NB-04/05/25/28–32　建议 40 分钟

## 1. 三个学派与图灵测试

| 学派 | 核心主张 | 典型代表 |
|---|---|---|
| 符号主义（Symbolism） | 智能 = 符号操作与逻辑推理 | 专家系统、规则引擎、逻辑程序 |
| 联结主义（Connectionism） | 智能 = 大量简单单元的连接与学习 | 神经网络、深度学习 |
| 行为主义（Behaviourism） | 智能 = 与环境的交互中涌现的行为 | 强化学习、机器人 |

**图灵测试**：让测试者通过文字对话分辨"人"与"机器"，若分不出，就认为机器具有智能。
它测的是**行为**，不是内部机制。**中文屋子**是它的经典反驳：屋子里的人按规则表操作汉字，
外部看像懂中文，内部并不理解——说明"通过测试"不等于"理解"。

## 2. 机器学习范式

| 范式 | 数据 | 目标 | 例子 |
|---|---|---|---|
| 监督学习 | 带标签 | 学输入→标签的映射 | 分类、回归 |
| 无监督学习 | 无标签 | 发现结构 | 聚类、降维 |
| 半监督学习 | 少量标签 + 大量无标签 | 用无标签数据辅助 | 半监督分类 |
| 强化学习 | 与环境交互的奖励 | 学策略使累计奖励最大 | 游戏、机器人控制 |

强化学习的关键词：**智能体（agent）、环境、状态、动作、奖励、策略、价值**。
它与监督学习的区别：没有"标准答案"，只有延迟的奖励信号。

## 3. 伦理问题

| 类型 | 表现 | 应对 |
|---|---|---|
| 技术限制 | 偏见（训练数据不均衡）、幻觉（编造事实）、遗忘（旧知识丢失） | 数据审核、检索增强、人工复核 |
| 不当使用 | 认知外包（把判断全交给模型）、隐私与版权侵害、深度伪造 | 告知同意、脱敏、标识 AI 生成内容 |
| 大规模应用 | 就业结构变化、信息茧房、责任归属不清 | 政策监管、分级分类管理 |
| 道德悖论 | 自动驾驶的"电车难题"类取舍 | 透明规则、人类最终负责 |

**责任归属**：模型不是法律主体，责任在**使用者与提供者**。LLM 的输出是"涌现的技术现象"，
不能像自然人一样承担责任；重要决策必须有人复核。

## 4. AI4S（AI for Science）

**基本思想**：用机器学习/深度学习加速科学发现，形成
"观察 → 假设 → 实验 → 数据 → 模型 → 再假设"的闭环。

**典型范式**：

- 数据驱动建模（用数据拟合科学规律）
- AI 辅助文献/知识抽取
- 实验自动化（自主实验室、闭环实验）
- 可微仿真（把仿真嵌入训练）
- 生成式模型设计分子与材料

**代表性进展**：AlphaFold（蛋白质结构预测）、AI 辅助材料发现、气候与物理建模、
分子动力学加速。

**科学数据与评价的四个问题**：数据集与基准怎么建、不确定性怎么量化、结果能否复现、
跨模态/多保真数据怎么融合。

## 5. 前沿趋势（名词解释级）

| 名词 | 一句话 |
|---|---|
| LLM | 大规模预训练的语言模型，核心是"预测下一个词元" |
| 多模态 | 同时处理文本、图像、音频等多种数据 |
| Agent（智能体） | 能规划、调用工具、多步执行任务的模型系统 |
| 具身智能 | 有身体、能与物理环境交互的智能 |
| Vibe Coding | 用自然语言描述意图、由模型生成并迭代代码的编程方式 |
| 规模定律 | 模型效果随参数、数据、算力按幂律提升的经验规律 |
| 世界模型 | 学习环境动态、能预测"动作之后会怎样"的内部模型 |

## 6. 自测

1. 中文屋子反驳的是图灵测试的哪一点？
2. 半监督学习与强化学习的"数据"分别是什么？
3. 模型幻觉属于哪一类伦理问题？应对手段是什么？
4. AI4S 的闭环有哪几步？
5. AlphaFold 属于 AI4S 的哪种范式？

> [!note]- 答案
> 1. 通过行为测试不等于真正理解。
> 2. 半监督：少量带标签 + 大量无标签数据；强化学习：与环境交互得到的奖励序列。
> 3. 技术限制类；数据审核、检索增强、人工复核、标注"仅供参考"。
> 4. 观察 → 假设 → 实验 → 数据 → 模型 → 再假设。
> 5. 数据驱动建模（用已知结构数据预测蛋白质三维结构）。
