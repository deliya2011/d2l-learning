## 1. 排序

| 算法 | 思想 | 平均复杂度 | 最坏 | 稳定 |
|---|---|---|---|---|
| 冒泡 | 相邻比较交换，大的往后沉 | $O(n^2)$ | $O(n^2)$ | 是 |
| 选择 | 每轮选最小的放到前面 | $O(n^2)$ | $O(n^2)$ | 否 |
| 插入 | 把元素插到已排好的前缀里 | $O(n^2)$ | $O(n^2)$ | 是 |
| 快速 | 选基准，小的放左、大的放右，递归 | $O(n\log n)$ | $O(n^2)$ | 否 |

**冒泡第一趟**：从头到尾相邻比较，最大的会到末尾。
**快排第一趟**：以第一个元素为基准，双指针"先右后左"交换，最后基准归位。

## 2. 查找

- **顺序查找**：逐个比较，$O(n)$，不要求有序
- **二分查找**：要求**有序**，每次砍一半，$O(\log n)$

```python
def binary_search(a, target):
    lo, hi = 0, len(a) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if a[mid] == target:
            return mid
        elif a[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1
```

## 3. DFS 与 BFS

| | DFS | BFS |
|---|---|---|
| 数据结构 | 栈 / 递归 | 队列 |
| 走法 | 一条路走到黑，再回溯 | 一层一层扩展 |
| 找最短路径（边数） | 不保证 | 无权图上保证 |
| 适用 | 连通性、拓扑、回溯 | 最短步数、层级遍历 |

**必须记录已访问**，否则有环的图会无限循环。

## 4. 贪心

每一步选当前最优，不回头。**不一定全局最优**，要能证明或举反例。

- 有效：找零（特定面额）、活动选择、最小生成树的 Kruskal/Prim
- 失效：0/1 背包（按单位价值贪心会错）、任意面额找零

## 5. 伪代码与流程图

伪代码用接近自然语言的步骤描述算法，不绑定语法；流程图用开始/结束、处理、判断、输入输出
四类框表示流程。写伪代码时把**循环与判断**写清楚即可。

## 6. 集合与韦恩图

$A\cap B$（交）、$A\cup B$（并）、$A-B$（差）、补集。
容斥：$|A\cup B|=|A|+|B|-|A\cap B|$。

## 7. 有限状态自动机

由**状态集合、输入字母表、转移函数、初始状态、接受状态**组成。
例：自动门（关闭/打开，人来自动开、超时关闭）；售货机（投币/选择/出货）。

## 8. 正反馈与负反馈

- **正反馈**：输出增强输入，偏离被放大（麦克风啸叫、恐慌性抢购）
- **负反馈**：输出抑制输入，系统趋于稳定（恒温器、血糖调节）

3. 无权图上找"最少步数"，用 DFS 还是 BFS？

5. 恒温器属于正反馈还是负反馈？

> [!note]- 答案
> 1. 相邻比较，把最大值送到末尾；`[2,5,1,9]`。
> 2. 数据有序；$O(\log n)$。
> 3. BFS。
> 4. 容量 10，物品 A(重量 6, 价值 6)、B(重量 5, 价值 4.9)、C(重量 5, 价值 4.9)。单位价值 A=1、B=C=0.98，
贪心先选 A，剩 4 装不下 B/C，总价值 6；最优是 B+C=9.8。
> 5. 负反馈。
