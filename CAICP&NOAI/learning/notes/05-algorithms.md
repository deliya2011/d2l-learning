## 1. 排序

| 算法 | 思想 | 平均复杂度 | 最坏 | 稳定 |
|---|---|---|---|---|
| 冒泡 | 相邻比较交换，大的往后沉 | $O(n^2)$ | $O(n^2)$ | 是 |
| 选择 | 每轮选最小的放到前面 | $O(n^2)$ | $O(n^2)$ | 否 |
| 插入 | 把元素插到已排好的前缀里 | $O(n^2)$ | $O(n^2)$ | 是 |
| 快速 | 选基准，小的放左、大的放右，递归 | $O(n\log n)$ | $O(n^2)$ | 否 |

**冒泡第一趟**：从头到尾相邻比较，最大的会到末尾。
**快排第一趟**：以第一个元素为基准，双指针"先右后左"交换，最后基准归位。

例：`[9,2,15,7,4,11,6]`，基准 9：

1. 右指针从 6 往左找比 9 小的 → 6；左指针从 2 往右找比 9 大的 → 15；交换 → `[9,2,6,7,4,11,15]`
2. 右指针继续从 11 往左 → 4；左指针从 6 往右 → 11；交换 → `[9,2,6,7,4,11,15]`（指针相遇前）
3. 指针相遇在 4，基准与 4 交换 → `[4,2,6,7,9,11,15]`

**复杂度**：快排平均 $O(n\log n)$（每次大致平分），最坏 $O(n^2)$（每次只分出一个元素，
如已有序且取首元素为基准）。归并排序稳定且最坏 $O(n\log n)$，但要额外空间。

## 2. 查找

- **顺序查找**：逐个比较，$O(n)$，不要求有序
- **二分查找**：要求**有序**，每次砍一半，$O(\log n)$

```python
def binary_search(a, target):
    lo, hi = 0, len(a) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if a[mid] == target:
            return mid
        elif a[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1
```

## 3. DFS 与 BFS

| | DFS | BFS |
|---|---|---|
| 数据结构 | 栈 / 递归 | 队列 |
| 走法 | 一条路走到黑，再回溯 | 一层一层扩展 |
| 找最短路径（边数） | 不保证 | 无权图上保证 |
| 适用 | 连通性、拓扑、回溯 | 最短步数、层级遍历 |

**必须记录已访问**，否则有环的图会无限循环。

**复杂度**：邻接表存图时，DFS/BFS 都是 $O(V+E)$；邻接矩阵是 $O(V^2)$。
DFS 的递归深度可能达到 $V$，大图要改显式栈。

## 4. 贪心

每一步选当前最优，不回头。**不一定全局最优**，要能证明或举反例。

- 有效：找零（特定面额）、活动选择、最小生成树的 Kruskal/Prim
- 失效：0/1 背包（按单位价值贪心会错）、任意面额找零

**正确性怎么说明**：常用**交换论证**——假设最优解与贪心解在第一步不同，把最优解里的选择
换成贪心选择，证明不会变差。换得动，贪心就对；换不动，就找反例。

## 5. 伪代码与流程图

伪代码用接近自然语言的步骤描述算法，不绑定语法；流程图用开始/结束、处理、判断、输入输出
四类框表示流程。写伪代码时把**循环与判断**写清楚即可。

## 6. 集合与韦恩图

$A\cap B$（交）、$A\cup B$（并）、$A-B$（差）、补集。
容斥：$|A\cup B|=|A|+|B|-|A\cap B|$。

## 7. 有限状态自动机

由**状态集合 $Q$、输入字母表 $\Sigma$、转移函数 $\delta:Q\times\Sigma\to Q$、初始状态 $q_0$、
接受状态集 $F$** 组成。

例：自动门 $Q=\{\text{关},\text{开}\}$，$\Sigma=\{\text{有人},\text{超时}\}$；
售货机状态 `待机/已投币/出货`，事件 `投币/选择/取货`。

做题时画**状态转移表**（行是状态、列是事件），再按输入序列逐条走。

## 8. 正反馈与负反馈

- **正反馈**：输出增强输入，偏离被放大（麦克风啸叫、恐慌性抢购）
- **负反馈**：输出抑制输入，系统趋于稳定（恒温器、血糖调节）

## 9. 自测

1. 冒泡排序第一趟做了什么？对 `[5,2,9,1]` 第一趟结果是什么？
2. 二分查找的前提是什么？复杂度是多少？
3. 无权图上找"最少步数"，用 DFS 还是 BFS？
4. 0/1 背包为什么不能按单位价值贪心？举一个反例。
5. 恒温器属于正反馈还是负反馈？

> [!note]- 答案
> 1. 相邻比较，把最大值送到末尾；`[2,5,1,9]`。
> 2. 数据有序；$O(\log n)$。
> 3. BFS。
> 4. 容量 10，物品 A(重量 6, 价值 6)、B(重量 5, 价值 4.9)、C(重量 5, 价值 4.9)。单位价值 A=1、B=C=0.98，
贪心先选 A，剩 4 装不下 B/C，总价值 6；最优是 B+C=9.8。
> 5. 负反馈。
